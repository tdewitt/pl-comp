# Compliance automation

The reusable Secureframe entry point is [secureframe/README.md](secureframe/README.md). Use `mise exec -- node secureframe/cli.js --help` for shared setup and `mise exec -- node secureframe/cli.js vendors help` for vendor review commands.

Vendor evidence and the current review tracker are under `vendors/`. Older root-level JavaScript files are prior risk-assessment experiments and are retained for migration into the suite.
